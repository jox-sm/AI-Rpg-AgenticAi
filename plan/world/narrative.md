# Narrative & Social System

## Overview
The narrative system features branching quests, moral choices, and dynamic storytelling. Social systems include reputation, relationships, and faction dynamics.

## Quest System

### Quest Types
| Type | Description | Reward |
|------|-------------|--------|
| Main Story | Critical path quests | Major XP, Legendary items |
| Side Quests | Optional content | XP, Rare items |
| Daily | Repeatable quests | Gold, Reputation |
| Weekly | Longer quests | Epic items |
| Event | Limited-time quests | Unique rewards |
| Procedural | Generated quests | Variable |
| Faction | Faction-specific quests | Faction reputation |
| Bounty | Kill targets | Gold |
| Exploration | Discover locations | XP, Maps |
| Crafting | Create items | Recipes, Materials |

### Quest Mechanics
- **Objectives**: Kill, collect, deliver, explore, talk
- **Scaling**: Quests scale with player level
- **Difficulty**: Easy, Normal, Hard, Nightmare
- **Time Limits**: Some quests have deadlines
- **Fail States**: Can fail certain quests
- **Multiple Solutions**: Various approaches
- **Branching Paths**: Choices matter
- **Hidden Objectives**: Secret conditions

### Quest Rewards
| Reward Type | Description |
|-------------|-------------|
| Experience | Character progression |
| Gold | Currency |
| Items | Equipment, consumables |
| Reputation | Faction standing |
| Titles | Cosmetic rewards |
| Abilities | New skills or spells |
| Stories | Lore and world-building |
| Unlock | New areas or features |

## Moral System

### Karma Scale
| Karma Level | Range | Effects |
|-------------|-------|---------|
| Legendary Hero | 1000+ | NPCs worship, discounts |
| Hero | 500-999 | NPCs thank, small discounts |
| Good | 100-499 | NPCs friendly |
| Neutral | -99 to 99 | Normal reactions |
| Evil | -100 to -499 | NPCs fear, higher prices |
| Villain | -500 to -999 | NPCs flee, hostile |
| Legendary Villain | -1000+ | NPCs attack on sight |

### Moral Choices
| Choice Type | Example | Consequence |
|-------------|---------|-------------|
| Selfless | Save villager | +Karma, -Gold |
| Selfish | Take reward | -Karma, +Gold |
| Ruthless | Kill enemy | -Karma, +Power |
| Merciful | Spare enemy | +Karma, -Reward |
| Honorable | Keep promise | +Karma, +Reputation |
| Deceptive | Break promise | -Karma, -Reputation |

### Karma Effects
| Karma Level | Shop Prices | NPC Reactions | Special Events |
|-------------|-------------|---------------|----------------|
| Legendary Hero | -30% | Adoration | Hero events |
| Hero | -15% | Friendly | Good events |
| Good | -5% | Positive | Normal |
| Neutral | Normal | Normal | Normal |
| Evil | +15% | Fearful | Evil events |
| Villain | +30% | Hostile | Dark events |
| Legendary Villain | +50% | Attack | Apocalypse |

### Moral Dilemmas
- **Trolley Problem**: Save many or save one
- **Greater Good**: Sacrifice few for many
- **Personal vs. Global**: Help self or world
- **Loyalty vs. Justice**: Friend or law
- **Power vs. Morality**: Strength or soul
