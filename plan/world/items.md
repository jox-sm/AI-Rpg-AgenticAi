Some enchantments combine for special effects:
- Flame + Frost = Steam Cloud (blind)
- Shock + Frost = Static Freeze (stun)
- Holy + Shadow = Void (anti-magic zone)
- Protection + Haste = Swift Shield (counter-attacks)

## Durability System

### Durability Mechanics
- Each item has 100 durability max
- Using items reduces durability
- Repair at blacksmiths or with repair kits
- 0 durability = item breaks (can be repaired)

### Degradation Effects
| Durability | Effect |
|------------|--------|
| 100-80 | Full effectiveness |
| 79-60 | -5% damage/defense |
| 59-40 | -10% damage/defense, visual wear |
| 39-20 | -20% damage/defense, may break |
| 19-1 | -30% damage/defense, high break chance |
| 0 | Item broken, unusable |

## Loot System

### Loot Grades
| Grade | Drop Rate | Quality |
|-------|-----------|---------|
| Common | 60% | Basic stats |
| Uncommon | 25% | Improved stats |
| Rare | 10% | Good stats + affix |
| Epic | 4% | Great stats + 2 affix |
| Legendary | 1% | Amazing stats + unique |

### Loot Sources
- **Enemies**: Drop based on type and level
- **Chests**: Random loot with guaranteed rarity
- **Shops**: Buy with gold
- **Quests**: Unique rewards
- **Crafting**: Player-made items
- **World**: Found in environment

This item system provides deep customization and progression through multiple interconnected systems.
